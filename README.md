# 环线坐车 - 校园环线时刻表助手

校园环线公交车时刻表查询与到站预测 PWA 应用，服务于国防科大校园师生。

## 功能特性

- **首页推荐**：基于 GPS 定位自动推荐最近站点，展示即将到站的车次
- **行程规划**：输入出发站、到达站和到达期限，查询可乘坐的车次
- **站点查询**：查看任意站点的到站预测信息
- **地图可视化**：高德地图展示三条环线路线、站点位置和实时公交车位置
- **手动记录**：乘车时手动计时记录站间耗时，数据上传至 Supabase
- **自动记录**：GPS 自动检测到站、记录段耗时、下车自动提交
- **历史记录**：查看和撤销已提交的乘车记录
- **PWA 离线**：支持添加到手机桌面，离线查看时刻表

## 技术栈

- **框架**：Vue 3 + TypeScript + Vite
- **状态管理**：Pinia
- **UI 组件**：Vant 4
- **地图**：高德地图 JS API 2.0
- **数据库**：Supabase
- **部署**：GitHub Pages（`docs/` 目录）

## 开发

```bash
npm install
npm run dev        # 本地开发
npm run build      # 构建到 dist/
npm run deploy     # 构建并复制到 docs/（用于 GitHub Pages 部署）
```

## 线路说明

| 线路 | 运行日期 | 发车点 |
|------|----------|--------|
| 环线1路 | 仅工作日 | 研究生宿舍楼 |
| 环线2路 | 工作日 + 周末/节假日 | 研究生宿舍楼 |
| 环线3路 | 工作日 + 周末/节假日 | 研究生宿舍楼 / 高超楼 |
| 就餐专线 | 仅工作日（就餐时段） | 高超楼 |

## 数据说明

到站时间为根据路线距离、校园限速和发车时刻估算，实际时间可能受上下客、道路情况和车辆调度影响。
